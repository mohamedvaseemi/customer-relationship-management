# ModernCRM | Enterprise Sales Intelligence

ModernCRM is a high-performance CRM platform designed for modern sales teams. It provides a robust, real-time interface for managing leads, deals, contacts, and business analytics with a focus on ease of use and professional aesthetics.

## Features
- **Intelligent Dashboard**: Real-time sales metrics and trends.
- **Entity Management**: Advanced tracking for Leads, Deals, Contacts, and Accounts.
- **ModernBot AI**: Integrated AI assistant for sales insights and automation.
- **Multi-Theme UI**: Six professional, carefully curated themes (Light, Dark, Midnight, Emerald, Sapphire, Onyx).
- **Responsive Layout**: Designed for both desktop and mobile productivity.

## Technology Stack
- **Frontend**: Next.js 16 (App Router), React 19, Framer Motion, Recharts.
- **Backend API**: Next.js API Routes, JWT Authentication, bcryptjs.
- **Database**: PostgreSQL with custom query pooling.

## Getting Started

First, run the development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Theme Management
The application supports persistent theme selection via `ThemeContext`. Local storage ensures your preference is remembered across sessions.

## Automation & Intelligence
- **Workflows**: Automated triggers for business logic.
- **ModernBot**: Natural language interaction with your CRM data.
